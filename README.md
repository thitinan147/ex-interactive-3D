# ex-interactive-3D

Interactive 3D product site for **Vektor V-9** (reusable rocket) — Astro + Three.js + GSAP.

Style and architecture reference: Lusion / [oryzo.ai](https://oryzo.ai/) (see `docs/`).

## Quick start

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
